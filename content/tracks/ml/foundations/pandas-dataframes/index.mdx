<Section kind="intuition" title="A spreadsheet you program">

Real <Term id="dataset">datasets</Term> are tables: one row per example, one column per measurement, and the
columns hold different kinds of values. The penguins table in this lesson has a species name, an island, four
measurements and the year for each of 344 penguins.

A <Term id="dataframe">DataFrame</Term> from the pandas library is that table in Python. Each column has a name
and its own type, and underneath each column is an array, so whole-column arithmetic is as fast as NumPy. On top,
pandas adds what spreadsheets do: read a CSV file, filter rows, sort, and summarize groups, each in one line.

</Section>

<Section kind="technical" title="Load, select, filter, group">

**Load and look.** `pd.read_csv("penguins.csv")` reads the file. `df.shape` is `(rows, columns)`, `df.head()`
shows the first 5 rows, `df.dtypes` the type of each column, and `df.isna().sum()` counts the missing values per
column. In this file, missing values are written `NA`, and pandas reads them as `NaN`.

**Select columns.** `df["body_mass_g"]` is one column, a `Series`. `df[["species", "island"]]` (a list inside
the brackets) is a smaller DataFrame.

**Filter rows.** `df["body_mass_g"] > 5500` is a mask with one True or False per row, as in NumPy, and
`df[mask]` keeps the True rows. Combine conditions with `&` (and), `|` (or) and `~` (not), with parentheses
around each condition. Rows keep their labels, the index printed on the left, so you can always find them in
the original file.

**Sort.** `df.sort_values("flipper_length_mm", ascending=False)` orders rows by a column. Add `kind="stable"` to
keep equal values in file order; otherwise their order is not guaranteed.

**Group and summarize.** `df.groupby("species")["body_mass_g"].mean()` splits the rows by species, takes the
body mass column of each group and averages it: one number per species, in sorted order. Summaries such as
`mean`, `count`, `min` and `max` skip missing values, and `groupby` leaves out rows whose group key is missing.
That is why `len(df)` and `df["body_mass_g"].count()` can differ.

</Section>

<Section kind="summary">

- A DataFrame is a table of named columns, each with its own type; `shape`, `head()`, `dtypes` and
  `isna().sum()` are the first things to look at.
- `df["col"]` selects a column, `df[mask]` filters rows; combine masks with `&` and `|` and parentheses.
- `groupby(key)[col].mean()` gives one summary per group; summaries skip missing values.
