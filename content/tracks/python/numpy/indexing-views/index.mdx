<Section kind="intuition" title="One block of memory, many windows">

A NumPy array is a block of numbers in memory plus a small description: shape, dtype and *strides* (how many
bytes to jump to reach the next row or column). Many operations change only the description and keep the same
block. `a[1]`, `a[:, 1]`, `a.T` and `a.reshape(4, 3)` are new windows onto the same numbers: free to make, and
any write through them lands in `a`.

Other operations must gather scattered elements into a new block: a list of positions, a boolean mask,
`flatten()`. Those are copies. Knowing which is which explains both speed (views cost nothing) and some nasty
bugs (writing into what you thought was a copy).

</Section>

<Section kind="technical" title="Indexing, views, copies and axes">

**Basic indexing** uses integers, slices (`start:stop:step`), `...` and `None`. It always returns an
<Term id="array-view">array view</Term>. Each integer index removes an axis: `a[1]` of a `(3, 4)` array has shape
`(4,)`, while the slice `a[1:2]` keeps it, `(1, 4)`.

**<Term id="fancy-indexing">Fancy indexing</Term>** uses an array or list of positions, `a[[0, 2]]`, and
**boolean masks**, `a[a > 8]`, which keep the elements where the mask is True. Both always return copies. A mask
result is always 1-D, because the kept elements need not form a rectangle. Assigning *through* either form, as in
`a[a > 8] = 0`, writes into `a`.

**Reshaping.** `reshape`, `.T` (transpose) and `ravel()` return views when the memory layout allows and copies
otherwise; `flatten()` and `.copy()` always copy. `np.shares_memory(a, b)` settles any doubt.

**Axes.** A reduction such as `sum`, `mean`, `max` or `argmax` with `axis=k` collapses axis `k`
(<Term id="axis">axis</Term>): for a `(rows, columns)` table, `axis=0` gives one value per column and
`axis=1` one per row. `keepdims=True` keeps the collapsed axis with length 1, so `(4, 3)` becomes `(4, 1)`, which
broadcasts straight back against the original.

**Combining masks.** Use `&`, `|` and `~` with parentheses around each comparison. Python’s `and`, `or` and
chained comparisons such as `25 <= ages < 50` need a single True or False and raise `ValueError` on arrays.

</Section>

<Section kind="mistakes" title="Views and masks gone wrong">

<CommonMistake
  title="Normalizing a slice of the original"
  wrong={'first = X[:100]\nfirst -= first.mean(axis=0)   # meant to work on a copy'}
  error="No error: the first 100 rows of X are now changed too."
  cause="A basic slice is a view, and -= writes into it."
  fix={'first = X[:100] - X[:100].mean(axis=0)   # new array\n# or: first = X[:100].copy()'}
/>

<CommonMistake
  title="Using and on arrays"
  wrong={'ages[(ages >= 25) and (ages < 50)]'}
  error="ValueError: The truth value of an array with more than one element is ambiguous. Use a.any() or a.all()"
  cause="and needs one True or False; a comparison on an array gives one per element."
  fix={'ages[(ages >= 25) & (ages < 50)]'}
/>

<CommonMistake
  title="Subtracting row means without keepdims"
  wrong={'X - X.mean(axis=1)   # X has shape (4, 3)'}
  error="ValueError: operands could not be broadcast together with shapes (4,3) (4,)"
  cause="(4,) aligns with the last axis, which has length 3."
  fix={'X - X.mean(axis=1, keepdims=True)   # (4, 1) stretches across columns'}
/>

<Section kind="practice" title="Where you will meet it">

| In data and ML code | What it does |
|---|---|
| `X_train, X_val = X[:800], X[800:]` | Two views of one array: free, but share memory |
| `X[idx]` with shuffled `idx` | A shuffled copy (fancy indexing) |
| `(X - X.mean(axis=0)) / X.std(axis=0)` | Per-feature standardization |
| `probs.argmax(axis=1)` | The predicted class for each row of a batch |
| `y[y == -1] = 0` | Relabel in place through a mask |

<Section kind="summary">

- Basic indexing, reshape, `.T` and `ravel` give views (shared memory); fancy indexing, masks, `flatten` and
  `copy` give copies.
- Writing into a view writes into the original; check with `np.shares_memory` when unsure.
- `axis=k` collapses axis `k`; `keepdims=True` keeps it as length 1 so the result broadcasts back.
- Combine masks with `&`, `|`, `~` and parentheses.
